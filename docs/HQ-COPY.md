# HQ Verdict Panel — the copy

Every user-visible string of the Verdict tab, generated from `ui/src/workspace/hq-copy.js`.
Do not edit this file by hand: edit the copy file, then regenerate with
`node ui/src/workspace/hq-copy-export.mjs > docs/HQ-COPY.md` and update the golden with
`UPDATE_GOLDEN=1 node --test ui/src/workspace/hq-copy.test.js`. Placeholders are shown in braces.

Plain is the manager register (default; full sentences, no file paths). Technical is the operator
register (terse; paths and receipt ids inline). The record is the subject of every negative sentence.

## The state-word switch (R8-VOCABULARY, ruling R-2026-09-23-8)

Design record §5 words: Proven · Not proven · In progress · Recorded · Needs a re-check
(plus Approved / Ready for approval on the decision). Decided per producing state:

| Producing state (engine) | Was | Now | Why |
|---|---|---|---|
| claim `supported`; ask `proven` | Proven | **Proven** | §5 has the same word. |
| claim `unsupported`; ask `claimed_only` | Not proven | **Not proven** | §5 has the same word. |
| claim/ask `unverifiable`, capture NOT degraded | Couldn't check | **Recorded** | A reading exists and settles nothing — §5's `recorded` exactly. |
| `insufficient_evidence` | Couldn't check | **Recorded** | Evidence is here; it does not decide. |
| `not_evaluated` | Couldn't check | **Recorded** | Read and set aside; still never its own state word — the Record line says why. |
| external adapter report, state not `failed` | Couldn't check | **Recorded** | A report exists and qualifies nothing. |
| acceptance criterion neither `verified` nor `failed` | Couldn't check | **Recorded** | The contract was evaluated; this line settled nothing. |
| attestation ground `integrity_incomplete`, `capture_degraded` | Couldn't check | **Fog** | A recording gap, not a reading — the same rule the panel already used. |
| promise `open`/`dropped`; ask `partial`/`scope_shrunk`/`untouched`/`dropped`/`refused`; stop `user_interrupt`/`error`/`permission_denied`/`context_limit` | Loose thread | **Loose thread — KEPT** | §5 has no word for a promise made and abandoned. "In progress" would assert work is underway when the record shows it stopped. |
| claim/ask `unverifiable` when capture IS degraded; `chain_intact_false`; `raw_files_missing` | Fog | **Fog — KEPT** | §5 has no word for "nothing was reliably recorded". "Recorded" would assert a reading exists; "Needs a re-check" would assert something was checked. |
| criterion with no link row (Change model only) | — | In progress | Already §5; unchanged by this switch. |
| criterion whose evidence no longer applies (Change model only) | — | Needs a re-check | Already §5; unchanged by this switch. |

Engine slugs are unchanged (`couldnt`, `couldnt_check`, `WORDKEY.couldnt = couldnt-check`):
they are keys and query tokens, never displayed, and saved views keep working.
No state changed meaning, and no verdict path was touched.

## States

- **Proven** — The record backs it (`proven`)
- **Not proven** — The record does not back it (`not_proven`)
- **Recorded** — Something ran, and it settles nothing (`couldnt`)
- **Loose thread** — Promised, and the record shows no follow-through (`loose`)
- **Fog** — Recording gap (`fog`)

## Detectors — engine id → Plain phrase

Plain never shows a detector id; Technical shows it in a code chip. An id with no entry renders with its underscores replaced.

- `test_run_failed` → the test run failed
- `reexecution_failed` → re-running the command failed
- `assertion_removed` → an assertion was removed from a test
- `assertion_weakened` → an assertion in a test was weakened
- `skip_marker_added` → a test was marked to be skipped
- `test_deleted` → a test was deleted
- `narrowed_run` → the run covered fewer tests than before
- `tests_ran_before_final_edit` → the tests ran before the last edit

## Banned tokens

## Never on the Verdict tab

Engine words that must not reach the panel ("events" as a headline count; "reading" as the engine noun — the verb in `phases.labels.read_record` is allowed by name; the rest anywhere): `events`, `check receipt`, `review point`, `reading (noun)`, `object`, `certify`, `unverified`.
